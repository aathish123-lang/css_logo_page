# 🌐 Navbar Design Using HTML and CSS

## 📌 About the Project
This project is a simple and clean navigation bar created using HTML and CSS. It includes a logo, navigation links, and a login button. ✨

## 🚀 Features
- 🎨 Simple and clean navbar design
- 🏷️ Logo section
- 🏠 Home, About, and Contact navigation links
- 🔐 Login button with hover effect
- 📐 Flexbox layout using CSS
- ⚫ Black background with white text
- 🟢 Green login button with hover color change

## 🛠️ Technologies Used
- 🧱 HTML5
- 🎨 CSS3
- 📦 CSS Flexbox

## 📂 Project Structure
```text
Navbar-Design/
├── index.html
├── style.css
└── README.md
```

## 📚 What I Learned
- 📝 Creating a navigation bar using HTML
- 📐 Using CSS Flexbox for layout alignment
- 🎨 Applying colors, padding, margin, and border radius
- 🔗 Styling navigation links
- 🖱️ Creating hover effects for buttons

## ▶️ How to Run
1. 📥 Download or clone this repository.
2. 💻 Open the project folder in Visual Studio Code.
3. 🌐 Open `index.html` in your browser.
4. 🖱️ Hover over the Login button to see the hover effect.
